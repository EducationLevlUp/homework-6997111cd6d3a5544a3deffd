# Иерархический AI-агент на LangChain

Python-скрипт, реализующий иерархического AI-агента для планирования списка покупок.
Главный агент вызывает инструмент `get_price`, внутри которого работает субагент
для генерации реалистичных цен.

## Структура проекта

```
shopping_agent.py   — основной скрипт агента
README.md           — этот файл
```

## Зависимости

```bash
pip install langchain langchain-openai pydantic
```

> **Примечание:** В условии указаны версии `langchain==1.2.10` и
> `langchain-openai==1.1.9`, которые на момент создания решения не существуют
> на PyPI. Установите актуальные стабильные версии без жёстких пингов.

## Внешние сервисы

Требуется **LM Studio**, запущенный локально:

1. Скачайте и установите [LM Studio](https://lmstudio.ai/)
2. Загрузите модель, поддерживающую **tool/function calling** (например,
   `meta-llama-3.1-8b-instruct-4bit` или `mistral-7b-instruct`)
3. Откройте вкладку **Local Server** и запустите сервер на порту `1234`
4. Убедитесь, что API доступен по адресу `http://localhost:1234/v1`

## Запуск

```bash
python shopping_agent.py
```

## Ожидаемый результат

В консоли появится цепочка вызовов инструментов и финальная таблица:

```
---
get_price({'product': 'молоко', 'city': 'Казань'})
---
get_price({'product': 'хлеб', 'city': 'Казань'})
---
get_price({'product': 'яблоки', 'city': 'Казань'})
---
Вот список покупок для Казани:

| Продукт | Цена (руб.) | Магазин |
|---------|-------------|---------|
| Молоко  | 89          | Магнит  |
| Хлеб    | 45          | Пятёрочка |
| Яблоки  | 120/кг      | Перекрёсток |

**Итого:** ~254 руб.
---
```

## Реализованные требования

- [x] Подключение к локальной LLM через `ChatOpenAI` с `base_url='http://localhost:1234/v1'`
- [x] `api_key=SecretStr('fake')`, `temperature=0.7`
- [x] Инструмент `get_price(product: str, city: str) -> str` с декоратором `@tool`
- [x] Внутри `get_price` — создание субагента через `create_agent`
- [x] Главный агент с `system_prompt='Ты помощник по планированию покупок'`
- [x] Вызов через `invoke` с запросом про молоко, хлеб, яблоки в Казани
- [x] Функция `format_message` для вывода цепочки сообщений
- [x] Defensive parsing для `tool_calls` (dict / object)
